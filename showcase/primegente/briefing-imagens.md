## ⚠️ Formato correto das URLs CDN Unsplash

As URLs acima usam o formato `photo-[ID]`. O formato correto para o CDN é:
```
https://images.unsplash.com/photo-[ID]?auto=format&fit=crop&w=1920&q=85
```
Exemplo para hero: `https://images.unsplash.com/photo-_4tpElFQemQ?auto=format&fit=crop&w=1920&q=85`

## Como Adicionar as Imagens

1. Abra a URL "Unsplash" de cada imagem no browser
2. Clique em "Baixar gratuitamente"
3. Renomeie o arquivo baixado com o nome exato da coluna "Arquivo"
4. Mova para a pasta `images/` ao lado do `index.html`
5. Atualize o HTML para referenciar `./images/[nome].jpg` em vez dos caminhos para v2
